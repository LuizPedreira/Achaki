#Fluxo público
Ao abrir o site, **não é solicitado login**. Os itens encontrados ficam visíveis publicamente. Ao abrir um item, a área de contato aparece protegida/ofuscada. O botão de login leva à autenticação e, depois do login, o usuário retorna ao item e recebe o botão para conversar pelo WhatsApp.

#Funcionalidades implementadas
- Cadastro e login de usuários com senha armazenada em hash SHA-256 no navegador
- Perfis distintos: usuário e administrador
- Consulta pública de itens encontrados
- Busca e filtros por categoria, palavra-chave, local, período e status
- Cadastro de item encontrado com até 3 fotos e informação de posse atual
- Cadastro de item perdido
- Aprovação administrativa de novos itens
- Administração de status: Em aberto, Reservado, Devolvido
- Edição e exclusão administrativa
- Registro de devolução com data, proprietário, telefone, documento e observações
- Registro de devolução direta pelo usuário quando o item permanece com ele
- Histórico de devolvidos e não devolvidos
- Avaliação do processo de devolução
- Gestão de usuários e criação de administradores
- Configuração de categorias, locais, WhatsApp do setor e regras
- Backup e importação dos dados em JSON
- PWA/cache para uso em GitHub Pages

#Publicar no GitHub Pages
1. Envie **o conteúdo desta pasta** para a raiz da branch `main`.
2. GitHub > Settings > Pages.
3. Source: `Deploy from a branch`.
4. Branch: `main` e pasta `/(root)`.
5. Salve.

#Observação importante
GitHub Pages é hospedagem estática. O `localStorage` é local para cada navegador, então dois celulares diferentes não compartilham os mesmos cadastros. Para uma versão real multiusuário, será necessário substituir a camada de armazenamento por Supabase ou outro backend/banco de dados.
